# NumberGuess · 微信猜数字小游戏

原 Java ME 猜数字游戏的微信小游戏版本。采用原生 Canvas 绘制和触摸数字键盘，无第三方依赖、登录、后端或云开发。旧 Java 源码和 JAR 保留，不进入小游戏包。

## 玩法

- 猜 4 个不重复数字，允许前导 0。A 表示数字和位置正确，B 表示数字正确但位置不同。例如答案 `0123`，猜 `0214` 得 `1A2B`。
- 简单 / 经典 / 困难分别为 12 / 8 / 6 次机会，默认经典。重复数字不能输入，不完整输入不扣次数。
- 点击画布数字键输入、删除、提交。记录超出区域时上下滑动查看，默认显示最近记录。
- 支持规则说明、重新开始、难度切换及本机战绩。放弃对局不计战绩。
- 结束后显示答案，数字键盘停止接收输入，点击“再来一局”重开。

## 开发者工具运行

1. 导入仓库根目录，项目类型为**小游戏**。
2. AppID 为 `wx567404f1c7e30f10`，源码目录 `minigame/`，入口 `game.js` 和 `game.json`。
3. 直接编译，无需安装依赖或构建 npm。当前微信账号须有此 AppID 权限。
4. 竖屏运行，适配安全区与高分屏；本机开发配置 `project.private.config.json` 不提交。

## 验证

Node.js 18+ 运行 `npm test`，验证生成、校验、A/B、各难度次数、最后一次猜中、战绩去重、保存恢复及小游戏控制器流程。测试中的平台 mock 不代替模拟器和真机验收。

模拟器验收流程：首屏 → 规则 → 数字键输入、重复数字和不完整提交 → 有效记录 → 胜负与答案 → 重新开始、难度切换确认 → 战绩 → 重新编译恢复 → 清空战绩。

已在微信开发者工具模拟器验证：Canvas 首屏、真实坐标触摸输入与提交、A/B 记录、获胜及键盘禁用、战绩画面、重新编译恢复和统计不重复。其余确认弹窗、失败分支由自动化逻辑测试覆盖，尚未进行真机验收。

## 数据

进度与战绩使用本机存储键 `numberGuess.v1`，按难度记录完成局数、胜场、胜率和获胜最少次数。清空战绩保留当前对局，清理微信数据会丢失所有记录。损坏数据重置并提示；保存失败提示检查空间。

不包含自动上传、发布或排行榜服务。
